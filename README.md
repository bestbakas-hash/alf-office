# 🏢 합동 비서실 · 알프 오피스

알프1(대장) · 알프2 · 알프3 세 비서의 **도트 오피스 + 상황판 + 지시 작성기**를 담은 정적 웹페이지입니다.
빌드 도구 없이 `index.html` · `style.css` · `app.js` · `data/office.json` 만으로 동작합니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 도트 오피스 SVG(책상·모니터·화분·말풍선), 상황판 카드, 지시 작성기 마크업 |
| `style.css` | 픽셀 감성 UI, 캐릭터 애니메이션(둥실·깜빡임·김·조명), 반응형 |
| `app.js` | `office.json` 로드 → 말풍선·카드·활동 로그 렌더, 복사/초안 저장(localStorage), 시계 |
| `data/office.json` | 비서 3명의 역할·상태·진행 작업·최근 완료, 활동 로그 |

## 상태 바꾸기

`data/office.json` 만 고치면 화면 전체(말풍선·카드·요약·활동 로그)가 함께 바뀝니다.

```json
{
  "id": "alf2",
  "status": "작업중",          // 작업중 | 대기중 | 완료
  "bubble": ["한 줄", "두 줄"],
  "current": [{ "title": "작업 이름", "state": "작업중", "progress": 64 }],
  "recent": [{ "title": "끝난 일", "when": "오늘 12:10" }]
}
```

## 로컬에서 보기

`fetch()` 로 JSON 을 읽기 때문에 파일을 더블클릭(`file://`)하면 상황판이 비어 보입니다.
아래처럼 간단한 서버로 열어 주세요.

```bash
cd alf-office
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```
